1. OBJETIVO DA BUILD 0.2

Construir a primeira versão verdadeiramente jogável de Nzila.

Esta Build NÃO existe para impressionar visualmente.

Ela existe para responder:

"O combate é divertido?"

================================================

2. META DE ENTREGA

Ao final da Build o jogador deverá conseguir:

Entrar em Vila Raiz
↓
Controlar Akin
↓
Andar
↓
Correr
↓
Atacar
↓
Usar Eco
↓
Lutar contra Agentes da Rasura
↓
Vencer ou perder

Sem erros críticos.

1. OBJETIVO DO PACOTE

Este pacote existe para permitir que Claude implemente a Build 0.2 sem:

- inventar arquitetura própria
- alterar o escopo aprovado
- adicionar funcionalidades não autorizadas
- reutilizar código legado

O objetivo é reconstruir a Build 0.2 de forma limpa, modular e escalável.
